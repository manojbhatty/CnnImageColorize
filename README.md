# CnnChess
This is a small project I did back in 2016-2017 or so for fun that I decided to publish here now so as not to lose it. 

## Concept
This one was before I did a cleaner GPU version (CnnImageColorizeGPU repo). Thinking of a chess board as an 8x8 image, train a CNN model to learn rules of chess and play. Both this and the GPU versions were also before newer more efficient python and AI libraries were available.
